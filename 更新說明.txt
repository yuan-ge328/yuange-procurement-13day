【更新前務必】
請同事先在舊版「資源」→「匯出進度 JSON」備份。
本版使用與 V1.1 相同的 localStorage 主鍵 yuange-procurement-20261108-v1，並將 V1.2 的新紀錄寫入其內部 v12 欄位，不會刪除舊版紀錄。
注意：Safari 和 iPhone 主畫面 App 可能各有儲存空間，請在同事慣用的主畫面 App 操作。

【GitHub Pages 部署】
1. 打開 https://github.com/yuan-ge328/yuange-procurement-13day
2. 在 Code 頁面點 Add file → Upload files。
3. 將此資料夾內 index.html、questions.js、days.js、mnemonics.js、manifest.webmanifest、sw.js、icon-192.png、icon-512.png 上傳並覆蓋同名檔案（不要把 ZIP 直接上傳）。
4. 點 Commit changes。GitHub Pages 使用 main / (root)，不需改 Settings。
5. 用網站網址 https://yuan-ge328.github.io/yuange-procurement-13day/ 確認頁首 V1.2。
6. iPhone 主畫面 App 網頁重新開啟，必要時完全關閉後再進；若仍是 V1.1，等待快取更新後重新開啟，不要先刪除 App（避免遺失儲存資料）。
7. 完成 1 題是非與 1 題選擇題測試，重啟後確認進度。
