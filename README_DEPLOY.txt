源格採購基礎衝刺教室 V1.1｜GitHub Pages 部署

1. 將 ZIP 解壓縮。
2. 在 GitHub 建立公開 repository，例如 yuange-procurement-13day。
3. 到 Add file > Upload files，把以下五個檔案上傳在儲存庫根目錄（不是上傳 ZIP）：
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
4. 到 Settings > Pages > Build and deployment：
   Source = Deploy from a branch
   Branch = main；Folder = /(root)；Save。
5. 網站發布後，iPhone 用 Safari 開啟網頁，分享 > 加入主畫面。

備註：教材內題目為 AI 原創示範題，非官方題庫。GitHub Pages 內容對外公開。
